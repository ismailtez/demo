## НАСТРОЙКА MOODLE

1. Открываем на http://192.168.100.2:80
2. Авторизуемся под логин - admin пароль - P@ssw0rd
3. Переходим в верху в ```Home``` ---> ````Settings```
4. Откроется страница настрйоки главной страницы ```Site home settings```
5. Вбиваем ```Full site name``` номер места
